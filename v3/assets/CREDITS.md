# Asset credits & licenses
Summary: CC0 = Poly Haven HDRI, ambientCG textures (unused), self-authored towers/metro. CC BY 4.0 (credit required, listed below and in the in-game FAQ) = the 7 Sketchfab skyscrapers + 2 car models. Nothing low-poly (no Kenney/Quaternius). Visual pass 10 (Nov 5) added no new downloads; it only re-grades materials (darker window fabric, more glowing atrium bands) in code.
- **Facade001, Facade006** PBR textures (ambientCG, CC0 1.0) are still in assets/tex but NO LONGER used: facades now use procedurally generated reflective curtain-wall textures (engine/towers.js).
- **modern_buildings_night_1k.hdr** — Poly Haven HDRI, CC0 (https://polyhaven.com/a/modern_buildings_night). Used only for glass reflections (clamped).
- **assets/models/tower_*.glb** — glTF 2.0 skyscraper library (12 archetypes x 4 heights: setbacks, cylinders, hero blade/crown towers, terraced gardens) generated by `tools/gen_towers.py` (self-authored geometry, public domain / CC0).
  Reason: no realistic CC0 skyscraper glTFs are anonymously downloadable (Poly Haven has none; Sketchfab downloads need an API token;
  Kenney/Quaternius are low-poly and excluded by the brief). Regenerate with `python3 tools/gen_towers.py`.
- three.js r160 (MIT) incl. GLTFLoader / RGBELoader / BufferGeometryUtils addons.
